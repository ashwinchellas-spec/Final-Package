# Engine Analyser

Launch from the project root with run_project('gui'). EngineAnalyser_v1 is a programmatic matlab.apps.AppBase application with eight tabs. Callback helpers delegate to the shared backend, and gui_action catches errors for display.

This is editable MATLAB .m source, not an App Designer .mlapp archive. Design View editing and a recorded desktop walkthrough are not delivered. The GUI integration test is included but unexecuted here. Read docs/USER_MANUAL.md for tab workflows and input conventions.
