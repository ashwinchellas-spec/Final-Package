# Verification and runtime reports

HOST_AUDIT_RESULTS.json records actual host SQLite and static source checks. SOURCE_PARSE_RESULTS.json records the source-parser run if available. FINAL_VERIFICATION_REPORT.md at the root and its PDF counterpart distinguish these checks from MATLAB execution.

Runtime validation certificates, MATLAB test-result files, regression baselines, ML metrics and session reports appear here only after the corresponding MATLAB commands actually execute. Their absence at delivery is intentional. No reference acceptance certificate or trained-model benchmark is prefilled.
