Fresh test protocol
The provided script freezes the existing model and the ratio rule, then generates
600 new random conditions with fixed seed 17092026 inside the saved bounds.
It reports the original and revised predictor on the same accepted simulator
points. Rejected simulation points are retained in CSV. Invalid ratio predictions
on accepted simulator points cause an error, not silent exclusion or a pass.
No optimization or retraining uses these fresh points. Repeating the script uses
the SAME fresh-test set; repetitions are not independent experiments.
If further tuning uses this test result, a new untouched final test will be needed.

The script verifies the saved fingerprint, reads the database, and writes only
new report files. It never overwrites your trained model or relaxes the production
validation gate. The derived review MAT is an audit artifact, not a drop-in model
for PREDICT_EXPERIMENTAL_ML. The existing predictor will still use the original TSFC.
All other engines are untouched. Manufacturer accuracy remains unverified.
